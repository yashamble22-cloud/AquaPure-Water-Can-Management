AquaPure – Water Can Management System

Project Description

AquaPure is a Water Can Management System developed to manage customers, water can orders, inventory, and reports.

Features

* Customer management
* Water can order management
* Inventory and stock management
* Reports and order history
* Database connectivity using MySQL

Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MySQL

How to Run

1. Install Node.js and MySQL.
2. Open the project folder in a terminal.
3. Run npm install.
4. Configure the database settings in a local .env file.
5. Run node server.js.
6. Open http://localhost:5000 in a browser.
